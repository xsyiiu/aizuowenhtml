# 考研英语作文 · 交互模板

把 27 版讲义拆成能点的模板：正文里点带虚线的短语就换句，方框里填题干里的词，边点边长成整篇，最后「复制全文」贴到答题纸。
纯前端，不需要登录、不需要装东西，手机浏览器打开就能用。

## 三个页面

| 页面 | 地址 | 内容 |
| --- | --- | --- |
| 大作文 · 交互模板 | <https://xsyiiu.github.io/aizuowenhtml/> | 英一英二通用，10 种题型 + 真题预设 |
| 小作文 · 交互模板 | <https://xsyiiu.github.io/aizuowenhtml/xiaozuowen.html> | 书信 / 通知 / 纪要，100 词 |
| 考研政治 · 史纲 | <https://xsyiiu.github.io/aizuowenhtml/zhengzhi.html> | 时空地图、重大会议、一页纸口诀、刷题 |

三个页面顶栏互相有入口，草稿各存各的，互不影响。

## 怎么用

1. 顶上选题型；带真题的预设点一下，题干里的人名、数字、地点会自己填好。
2. 正文里带虚线的短语都能点，弹出几句同类表达，选一句就替换进去。
3. 方框里补题干信息（谁、多少、哪儿），填完句子自动连起来；留空就用通用说法。
4. 点「复制全文」整篇按段落复制，粘到答题纸或备忘录都行。

页面里点 **使用说明** 能看完整版：按钮逐个解释、设置项、云端存档、常见问题，滚到底还有全部版本的更新记录。

## 功能

- **点短语换句**：每个位置给几句写法，点一下就换，句子按语法自动拼接
- **真题预设**：按年份题型填好题干数据，选完直接改词
- **自动保存**：草稿、自动快照、收藏的句子存在本机浏览器里，关掉再开还在
- **撤销 / 重做 / 快照**：改坏了能退回去，重要版本可以手动存一个快照
- **星标收藏**：喜欢的句子点星，下拉列表里带 ★，设置里能统一看
- **云端存档**：填一个名字，把内容传到云端；换设备填同一个名字点「下载」就拉回来
- **字号 / 界面模式 / 题目浮窗**：都只在这台设备生效，手机和平板各调各的
- **数据备份**：导出 / 导入 JSON，换浏览器或清过数据也能恢复
- **建议栏**：不用注册，写个代号就能提建议，所有人都能看
- **常亮 / 收起顶栏**：背诵时不锁屏，正文多出两屏
- **检查更新**：有新版本按钮右上角出现小红点

## 云端存档规则

- 上传内容包括：大作文和小作文的草稿、自动快照、收藏的句子、设置
- 按用户名覆盖同一条存档，不会越传越多；换设备填同一个名字即可下载
- 下载前自动把本机这份另存，设置里有「撤销上次下载」
- **不上传也不覆盖**：字号、界面模式、题目浮窗的位置和大小（每台设备自己调）
- 用户名和建议栏共用一个，两边改哪边都同步
- 存档走 GitHub Issues 的私有约定（标题前缀 `存档｜`），公开可见，别放隐私内容
